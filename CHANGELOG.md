# Changelog

## 1.0.3

- Added `chrome://version/` instructions for finding the active Chrome Profile Path.
- Added Chrome version guidance for troubleshooting and issue reports.
- Added common Windows, macOS and Linux Chrome profile / Preferences paths.
- Added explicit instructions to terminate all `chrome.exe` processes before installation.
- Added `Run as administrator` as a Windows permissions troubleshooting fallback.
- Expanded troubleshooting steps for profiles that install on disk but do not appear in DevTools.

## 1.0.2

- Added on-disk verification after installation.
- Added `DOCTOR_WINDOWS.bat`.
- Added Chrome-running detection.
- Simplified custom-device JSON for wider Chrome compatibility.
